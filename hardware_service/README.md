# Modul 4 — Hardware & Service Management Linux

Modul ini membahas perintah Linux yang digunakan untuk melihat informasi perangkat keras, melakukan troubleshooting jaringan, serta mengelola service dan identitas sistem Linux.

---

## Tujuan Pembelajaran

Setelah mempelajari modul ini, diharapkan dapat:

- Mengenali informasi hardware pada sistem Linux
- Mengelola service dan proses sistem
- Memahami dasar administrasi user dan jaringan
- Menggunakan tools terminal untuk troubleshooting

---

## Daftar Perintah

| Perintah    | Fungsi |
|-------------|---------|
| `whereis`   | Menampilkan lokasi binary, source, dan manual suatu perintah |
| `wc`        | Menghitung jumlah baris, kata, dan karakter pada file |
| `nc`        | Tool networking untuk testing dan debugging koneksi |
| `nslookup`  | Mengecek DNS record dan proses resolve domain |
| `systemctl` | Mengelola service pada sistem Linux |
| `hostname`  | Menampilkan atau mengubah hostname sistem |
| `id`        | Menampilkan UID, GID, dan grup user |
| `groupadd`  | Membuat grup baru |
| `finger`    | Menampilkan informasi user |
| `cp`        | Menyalin file atau direktori |
| `tar`       | Mengarsipkan dan mengekstrak file |
| `arp`       | Menampilkan tabel ARP jaringan |
| `route`     | Menampilkan tabel routing |
| `lynx`      | Browser terminal berbasis teks |
| `lsusb`     | Menampilkan perangkat USB yang terhubung |
| `figlet`    | Membuat teks banner di terminal |

---

## Catatan

- Gunakan `sudo` atau akses root untuk beberapa perintah administrasi sistem
- `systemctl status <service>` digunakan untuk melihat status service
- `nc` sering digunakan untuk testing port dan komunikasi jaringan
- `tar` sangat umum digunakan untuk backup dan distribusi file di Linux
