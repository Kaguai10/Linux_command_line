# Modul 1 — Perintah Dasar Linux

Modul ini membahas perintah-perintah dasar Linux yang wajib dipahami sebelum mempelajari administrasi sistem, networking, maupun cyber security. Fokus utama modul ini adalah navigasi direktori, pengelolaan file, dan penggunaan terminal Linux secara efektif.

---

## Tujuan Pembelajaran

Setelah mempelajari modul ini, diharapkan dapat:

- Memahami fungsi dasar command line Linux
- Mengelola file dan direktori melalui terminal
- Menggunakan perintah Linux untuk kebutuhan sehari-hari
- Memahami struktur navigasi direktori di Linux

---

## Daftar Perintah Dasar

| Perintah   | Fungsi |
|------------|---------|
| `who`      | Menampilkan user yang sedang aktif |
| `whoami`   | Menampilkan user yang sedang digunakan |
| `pwd`      | Menampilkan lokasi direktori saat ini |
| `cd`       | Berpindah direktori |
| `cd ..`    | Kembali ke direktori sebelumnya |
| `ls`       | Menampilkan isi direktori |
| `ls -l`    | Menampilkan isi direktori secara detail |
| `touch`    | Membuat file kosong |
| `mkdir`    | Membuat direktori baru |
| `rm`       | Menghapus file |
| `rmdir`    | Menghapus direktori kosong |
| `cp`       | Menyalin file atau direktori |
| `mv`       | Memindahkan atau mengganti nama file |
| `find`     | Mencari file atau direktori |
| `history`  | Menampilkan riwayat perintah terminal |
| `man`      | Menampilkan dokumentasi perintah |
| `clear`    | Membersihkan tampilan terminal |
| `reboot`   | Merestart sistem |

---

## Catatan

- Gunakan `TAB` untuk auto-complete nama file atau direktori
- Gunakan `man <perintah>` untuk melihat dokumentasi lengkap
- Biasakan menggunakan terminal untuk mempercepat pekerjaan di Linux
